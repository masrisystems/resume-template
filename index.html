Daily Job Discovery & Application Routine

SOP · 20-Min Daily Cycle

A disciplined 4-stage, 8-step daily routine designed to qualify and prepare complete application packages for target vacancies scoring ≥ 9.0/10 while strictly preserving master resume integrity. Governed by daily-job-search-workflow.md.

Stage 1 08:00 - 08:05

Deduplication & Active Sourcing

Scan target portals and venture directories while filtering out past applications.

  • Step 1: Dedupe Tracker — Read jobs/job_matches.md to build normalized company and URL sets; eliminate duplicates instantly.
  • Step 2: Boolean Sourcing — Query LinkedIn DE, StepStone, Indeed, Techstars Directory, and HTGF Newsroom using pre-configured search queries.
Stage 2 08:05 - 08:10

Qualification Scoring & Preservation

Rank vacancies against candidate invariants and preserve authentic job postings.

  • Step 3: Weighted Scoring — Compute 70% required / 30% preferred criteria score (0-10 scale). Filter dealbreakers and map to Canonical Role Archetype.
  • Step 4: Evidence Archiving — Save raw description to jobs/job_descriptions/[slug].txt and benchmark salary against kununu evidence.
Stage 3 08:10 - 08:15

Automated Generation & QA Gates

Compile tailored HTML resumes, DIN-5008 cover letters, and high-fidelity PDFs.

  • Step 5: Resume Hydration — Initialize config and generate tailored resume with 100% DOM structure parity and zero schema bloat.
  • Step 6: DIN-5008 Cover Letter — Enforce STAR hook, 3 key problems solved, under 300 words, 0 n-gram overlap, burstiness range ≥ 20, and candidate invariants.
Stage 4 08:15 - 08:20

Pipeline Tracking & Zero-Bloat Review

Update application matrix and evaluate master resume improvements.

  • Step 7: Tracker Update — Append row to jobs/job_matches.md with direct submission status and official apply link.
  • Step 8: Zero-Bloat Review — Review daily work logs against master resume: 0 new sections, 0 new bullets, 0 word-count growth.

DIN-5008 Cover Letter

Claude 3.7 · GPT-4o

Generates a tailored German tech cover letter using the STAR method, verified project metrics, and DIN-5008 compliance.

# Rolle: Tech-Recruiter & Werbetexter # Aufgabe: Maßgeschneidertes Anschreiben für {{COMPANY}} # Struktur: STAR-Hook, 3 Kernprobleme lösen, Tech-Stack quantifizieren
# Rolle
Handeln Sie als fachkundiger Tech-Recruiter und professioneller Werbetexter mit Spezialisierung auf Anschreiben für Entwickler.

# Aufgabe
Lesen Sie das Kandidatenprofil (@config/profile.json), den Basis-Lebenslauf (@index.html) sowie die kanonischen Rollenprofile (@jobs/roles/*.json). Ich werde Ihnen eine spezifische Stellenbeschreibung zur Verfügung stellen. Ihre Aufgabe ist es, ein hochgradig maßgeschneidertes, überzeugendes Anschreiben zu verfassen, das den Hintergrund des Kandidaten perfekt mit den Anforderungen dieser Rolle in Einklang bringt.

# Anweisungen
1. Reale Projekterfahrungen nutzen: Ziehen Sie konkrete Architekturen, Tools, Performance-Erfolge und Projekte aus @index.html und den Rollendefinitionen heran, um authentische, überprüfbare Beweise für die Fähigkeiten zu liefern.
2. Kein Roboter-Ton: Das Anschreiben darf NICHT wie eine generische KI-Vorlage klingen. Vermeiden Sie typische KI-Buzzwords, Klischees oder übertrieben formelles Füllmaterial. Der Ton soll selbstbewusst, professionell und authentisch enthusiastisch sein.
3. Starker Aufhänger (Hook): Beginnen Sie das Anschreiben mit einem fesselnden ersten Absatz, der sofort die Aufmerksamkeit weckt, die angestrebte Rolle nennt und die relevanteste Qualifikation für genau dieses Unternehmen hervorhebt.
4. Bedürfnisse adressieren: Identifizieren Sie die 3 wichtigsten Anforderungen oder Kernprobleme aus der Stellenbeschreibung. Nutzen Sie den Hauptteil, um präzise zu zeigen, wie die bisherige Erfahrung diese Probleme löst, und quantifizieren Sie den Impact.
5. Kern-Technologien hervorheben: Betonen Sie gezielt die im Profil definierten Kerntechnologien sowie Enterprise-DevOps (Docker, CI/CD).
6. Kompakt & Prägnant: Halten Sie das Anschreiben kurz, überzeugend und strikt unter 300 Wörtern (maximal 3-4 Absätze).
7. Handlungsorientierter Schluss: Enden Sie mit einem starken Call-to-Action und der klaren Motivation für ein persönliches Kennenlernen.
8. Automatisierung: Speichern als JSON-Konfiguration in jobs/configs/JJJJ-MM-TT_[slug].json zur Kompilierung mit python jobs/engine.py run --config ...

Python Automation Engine Architecture

Modular CLI Engine · Python 3.10+

The repository includes a decoupled Python automation engine (jobs/engine.py and engine/*). It automates candidate config hydration, canonical role compilation, ATS structural validation, DIN-5008 cover letter rendering, and headless Chromium vector PDF compilation.

engine/config.py SSOT Loader & Invariant Validator Parses config/profile.json (with fallback to profile.example.json). Validates schema, resolves candidate contractual invariants (salary, notice period, portfolio links), and catches prohibited domains.
engine/resume.py Tailored Resume Hydration Engine Hydrates resume.html with targeted keywords and canonical role profiles. Strictly enforces 100% DOM structure parity, tag sequencing, and bilingual attribute preservation.
engine/cover_letter.py DIN-5008 Cover Letter Compiler Generates print-ready German DIN-5008 HTML cover letters under 300 words. Enforces anti-AI formatting, burstiness variance (≥ 20 words), and runs 8-word sequence overlap checks against raw job postings.
engine/roles.py Canonical Role Archetypes Catalog Builds and manages pre-validated career archetypes (jobs/roles/*.json). Compiles all role resumes simultaneously to jobs/roles/html/ and vector PDFs.
engine/search_links.py Boolean Search Query Synthesizer Generates daily job search link dashboards (daily-job-search-links.md and workflows/search_links/) with pre-filtered Boolean queries across LinkedIn DE, StepStone, Indeed, Techstars, and HTGF.
engine/pdf.py Headless Chromium PDF Compiler Drives headless Chrome/Chromium via Playwright or subprocess to compile selectable vector A4 PDFs for both resumes and 1-page DIN-5008 cover letters with exact print layout.
